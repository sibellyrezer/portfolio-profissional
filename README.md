# Portfólio Profissional — Sibelly Rezer

Repositório criado para a disciplina de **Design Profissional** do curso de Tecnologia em Análise e Desenvolvimento de Sistemas.

## Objetivo

Aplicar na prática os conceitos da trilha **GitHub Foundations** (Microsoft Learn) — repositório, commits, branches, pull request e merge — e reunir em um só lugar as evidências da minha identidade profissional.

## Tecnologias usadas

- Git e GitHub
- Markdown
